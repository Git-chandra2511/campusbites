# CampusBites — LPU Food Stall Directory & Review Portal

## Folder Structure
- `index.html` — Main HTML layout, fonts, Tailwind theme, and navbar
- `css/style.css` — Custom hero entrance, gradient shimmer, float, hover, and scroll-reveal animations
- `js/data.js` — 15 real LPU campus pure-veg outlets, 60 menu items, and 21 student reviews
- `js/state.js` — App state and `localStorage` persistence for favorites & reviews
- `js/helpers.js` — Rating math, date formatting, star rendering, and toast notifications
- `js/components.js` — Reusable UI cards (stall card, review card, skeleton loader, footer)
- `js/screens.js` — Page renderers for all 8 screens (Home, Explore, Details, Reviews, Favorites, Admin)
- `js/app.js` — Click handlers, modals, count-up stats, scroll reveal, Chart.js, and main `render()` function
- `images/` — Food photography and 3D CampusBites logo

## How to Run
1. Extract this ZIP folder.
2. Double-click `index.html` to open it in any browser (or open the folder in VS Code with Live Server).
